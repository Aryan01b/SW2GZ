SW2GZ — Preview panel direction picker

Four standalone mockups. Click into each, scroll the sidebar, expand a section. Pick one direction (or a hybrid). The chosen layout gets ported into the live in-addin preview/index.html.

Option A

Outliner — hierarchical, collapsible

Single column. Parent-child link tree replaces the flat list. Every section collapses with a chevron. Tightly packed monospace info. Inspired by Blender's outliner.

Sidebar: 280 px Best for: deep trees Scroll: vertical
Option B

Tabbed — focused panes, no scroll soup

Top tabs: Scene / Properties / Validation / Source. Each tab shows one thing. Selecting a link in Scene auto-switches to Properties. Stays compact regardless of model size.

Sidebar: 320 px Best for: wide models Always: filter bar
Option C

Split — tree + properties side-by-side

Wider sidebar, two columns. Left: hierarchy tree (always visible). Right: full properties of selected link/joint, persistent. Bottom strip: compact toggle row. Blender's outliner + properties editor.

Sidebar: 460 px Best for: heavy inspection Selection: persistent
Option D

Minimal — icon rail + slide-out drawers

60-px icon strip on the left. Click an icon → drawer slides out with that panel (Tree, Display, Validation, Joints). Click again to dismiss. Maximum 3D viewport real estate. HUD overlays for key facts. RViz-ish.

Rail: 60 px Best for: presentation Drawer: 280 px

📚 Joint-type reference — SW mates → URDF / SDF / ros2_control

Comprehensive mapping table. Every SOLIDWORKS mate type and what the exporter currently maps it to (or doesn't). Used by the Joints step in Create Robot, embedded here for cross-reference while picking a UI.

Mocks are static — no three.js, no live state. They exist to evaluate information density, hierarchy, and discoverability before any code lands. Real data (full_arm: 4 links / 3 revolute joints) is mirrored in each so the same model can be compared across layouts.
