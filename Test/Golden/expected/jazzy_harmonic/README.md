# three_dof_arm_description

Auto-generated by **SW2GZ** for ROS 2 **Jazzy** + Gazebo **Harmonic**.

## What's in this package

- `urdf/three_dof_arm_description.urdf.xacro` — robot description (links, joints, inertia).
  Anchored to a `world` link via a fixed joint so it stays put on spawn.
- `urdf/inc/ros2_control.xacro` — ros2_control hardware interface backed by
  `gz_ros2_control/GazeboSimSystem`. Every joint exposes position command +
  position/velocity/effort state.
- `urdf/inc/gz.xacro` — Gazebo system plugin (`gz_ros2_control-system`)
  loading the controller manager inside the sim.
- `urdf/inc/materials.xacro` — named visual materials (if any were tagged).
- `config/controllers.yaml` — `joint_state_broadcaster` +
  `joint_trajectory_controller` over all joints.
- `config/ros_gz_bridge.yaml` — `/clock`, `/joint_states`, `/tf` bridge.
- `worlds/empty.sdf` — empty Gz Harmonic world (physics, scene broadcaster,
  user commands).
- `launch/gz_sim.launch.py` — single-command bringup (see below).
- `meshes/` — per-link `.dae` (visual) and `.stl` (collision, convex hull).

## Build

```bash
cd three_dof_arm_description_ws
colcon build --symlink-install
source install/setup.bash
```

## Run

```bash
ros2 launch three_dof_arm_description gz_sim.launch.py
```

That single launch starts:

1. Gazebo Harmonic with `worlds/empty.sdf` (Gz viewport is the 3D view —
   no rviz needed).
2. `robot_state_publisher` from the xacro.
3. Spawns the robot into Gz.
4. `ros_gz_bridge` for clock + joint states + tf.
5. `joint_state_broadcaster` spawner, then
   `joint_trajectory_controller` spawner (chained after spawn).

## Command the robot

```bash
ros2 control list_controllers
ros2 topic pub --once /joint_trajectory_controller/joint_trajectory \
  trajectory_msgs/msg/JointTrajectory '{joint_names: [...], points: [...]}'
```

## Scope

Implemented: link geometry + inertia, joint connectivity + type + axis +
limits (with safe nonzero defaults), ros2_control wiring, single-command
Gz bringup, ros_gz bridge, world anchor.

Not implemented in this auto-generated package: tuned controller gains,
custom worlds, sensor calibration, MoveIt config. Drop those in alongside
(this package is meant as a working starting point, not a turnkey app).
